# 恋愛態度スコアリング

メッセージ履歴から、相手の自分に対する態度を **0（拒絶）〜 4（付き合いたい）** の
順序尺度で評価する。学習は行わない、ルールベース＋行動指標のスコアラー。

## なぜ機械学習にしないのか

「相手の本当の気持ち」という正解ラベルは原理的に手に入らない。自分で付けたラベルで
教師あり学習をさせても、モデルは自分の主観を再現するだけで、判断は冷静にならない。

そこで本ツールは 2 つの独立した根拠を分けて出す。

| 根拠 | 重み | 性質 |
|---|---|---|
| **行動指標** | 0.60 | 返信速度・会話開始率・誘いへの応答など、実際にとった行動。主観が入りにくい |
| **文面** | 0.40 | 語彙・絵文字の重み付け。辞書を書いた人の主観が入る |

主軸を行動側に置くのはこのため。文面だけを見て一喜一憂しないための設計になっている。

## 使い方

依存ライブラリなし（Python 3.10+ の標準ライブラリのみ）。

```bash
python3 main.py data/sample_messages.jsonl          # レポート出力
python3 main.py data/log.jsonl --json               # 機械可読な出力
python3 main.py data/log.jsonl --since 2026-06-01 --until 2026-07-01   # 期間を絞る
```

期間を変えて複数回かけると、態度の推移が見える（これが最も有用な使い方）。

```
2026-06-01 〜 2026-06-21 : 中立・友好   score=1.69  信頼度=中
2026-06-21 〜 2026-07-10 : 消極的      score=1.37  信頼度=低
2026-07-10 〜 2026-07-25 : 好意的      score=2.60  信頼度=低
```

## 入力形式

JSONL（1行1メッセージ）または JSON 配列。時系列は自動でソートされる。

```json
{"timestamp": "2026-06-01T21:03:00", "sender": "me",      "type": "text",     "text": "今日ありがとう"}
{"timestamp": "2026-06-01T21:20:00", "sender": "partner", "type": "text",     "text": "楽しかったです😊"}
{"timestamp": "2026-06-01T21:21:00", "sender": "partner", "type": "reaction", "text": "❤️", "reaction_to": 0}
```

| フィールド | 必須 | 内容 |
|---|---|---|
| `timestamp` | ✓ | ISO 8601。行動指標の算出に必須 |
| `sender` | ✓ | `me` / `partner` |
| `type` | | `text`（既定） / `reaction` / `sticker` / `image` / `call` |
| `text` | | 本文。リアクションの場合は絵文字そのもの |
| `reaction_to` | | リアクション対象メッセージの行番号（0 始まり） |

`timestamp` がないデータは行動指標が一切算出できず、文面だけの弱い判定になる。
エクスポート時は必ず日時を残すこと。

## 判定スケール

| レベル | ラベル | 意味 |
|---|---|---|
| 4 | 付き合いたい | 恋愛的好意がはっきり示されている |
| 3 | 好意的 | 関心を向けられている。可能性はあるが確定的ではない |
| 2 | 中立・友好 | 友人として良好。好意の証拠も否定の証拠も不足 |
| 1 | 消極的 | やり取りは続くが距離を取られている |
| 0 | 拒絶 | 恋愛的な関係を明確に断られている |

**決定的マーカー**（「友達としてしか見られない」「付き合いたい」など明示的な意思表示）を
検出した場合は、他の全指標を無視してそのレベルに固定する。本人が言葉にしたものより
確かな根拠はないため。拒絶と好意の両方がある場合は時系列で新しい方を採る。

## 行動指標

| 指標 | 重み | 見ているもの |
|---|---|---|
| 誘いへの応答（承諾率） | 0.30 | 自分の誘いに対し承諾 / 回避・断り / 曖昧のどれで返したか |
| 相手からの会話開始率 | 0.20 | 6時間以上の間隔で切れた会話を、どちらが再開したか |
| 返信速度（相手 / 自分） | 0.15 | 返信までの時間の中央値の比 |
| 相手からの質問率 | 0.15 | 相手がこちらに関心を向けているか |
| 発言が放置された率 | 0.10 | 自分の発言が24時間以上未返信だった割合 |
| リアクションのみ返信率 | 0.05 | 本文を返さず絵文字だけで済ませた割合 |
| 文量比（相手 / 自分） | 0.05 | メッセージ長の中央値の比 |

サンプル数が足りない指標は自動的に除外され、残った指標の重みで再正規化される。
除外された割合は「重み比」としてレポートに出る。

## 調整方法

判定に納得できない場合、直すのはモデルではなく **`affinity/lexicon.py` の辞書** と
**`affinity/features.py` の `METRIC_WEIGHTS`**。ルールベースなので、なぜその判定に
なったかは必ずレポートの根拠欄まで遡れる。

`ambiguous=True` を付けた語は誤検出しやすいもの（「好き」は物にも使う）で、
重みを低くした上でレポートに `(要確認)` と表示される。

## BERT 版

文面スコアを辞書ではなく日本語 BERT に判定させる実装が `bert/` にある。
「また今度で」と「また今度ゆっくり話したいです」のように、表層が同じで意味が逆の文を
辞書のメンテなしで区別できる。行動指標はそのまま使うため、あくまで文面層の置き換え。

学習からモデルを動かすまでの手順は **[BERT.md](BERT.md)** を参照。

```bash
uv venv --python 3.14 && ml-link
.venv/bin/python -m bert.train --data data/labeled_messages.jsonl --out models/affinity-bert
.venv/bin/python -m bert.predict models/affinity-bert "また今度ゆっくり話したいです"
```

## 限界

- これは相手の**言動の統計**であって、内心ではない。
- 語彙辞書は敬語・カジュアルの混在した日本語を想定しているが、相手の文体の癖
  （元々短文、元々返信が遅い）は補正できない。**絶対値より推移**を見ること。
- 信頼度「低」は判定ではなく単なるデータ不足。相手のメッセージ30通・観測期間14日が目安。
- 態度が中間にあるとき、それはたいてい本当に中間であって、読み取り不足ではない。
- 最終的な確認手段は、この出力ではなく本人に訊くことしかない。
