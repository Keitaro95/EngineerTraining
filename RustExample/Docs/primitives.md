# Primitives（基本データ型）

Rust にはさまざまな基本データ型（primitives）が用意されています。大きく「スカラ型（scalar types）」と「複合型（compound types）」に分けられます。

## スカラ型（scalar types）

1つの値を表す型です。

### 整数型（符号付き）

`i8`, `i16`, `i32`, `i64`, `i128`, `isize`（ポインタサイズ）

### 整数型（符号なし）

`u8`, `u16`, `u32`, `u64`, `u128`, `usize`（ポインタサイズ）

### 浮動小数点型

`f32`, `f64`

### その他

- `char` … Unicode のスカラ値（`'a'`, `'α'`, `'∞'` など）。それぞれ4バイト。
- `bool` … `true` または `false`。
- ユニット型 `()` … 値を持たない型。中身は空のタプル `()` だけ。

> ※「ユニット型」はタプルではありますが、複数の値を持たないので「複合型」とは見なされません。

## 複合型（compound types）

複数の値をまとめて1つにする型です。

- 配列（array）… 例：`[1, 2, 3]`
- タプル（tuple）… 例：`(1, true)`

## 変数への束縛と型注釈

変数は型注釈（type annotation）を付けて宣言できます。型を省略した場合、コンパイラが文脈から型を推論します。文脈だけで決まらない場合は、デフォルトの型（整数なら `i32`、浮動小数点なら `f64`）が使われます。

```rust
fn main() {
    // 変数に型注釈を付ける。
    let logical: bool = true;

    let a_float: f64 = 1.0;  // 通常の型注釈
    let an_integer   = 5i32; // サフィックス（接尾辞）による注釈

    // 型注釈を付けない場合は、デフォルトの型が使われる。
    let default_float   = 3.0; // `f64`
    let default_integer = 7;   // `i32`

    // 文脈から型が推論される場合もある。
    let mut inferred_type = 12; // 別の行での使われ方から `i64` と推論される。
    inferred_type = 4294967296i64;

    // `mut` を付けた変数は値を変更できる。
    let mut mutable = 12; // ミュータブルな `i32`
    mutable = 21;

    // ただし型は変更できない。これはエラーになる。
    // mutable = true;

    // ただし、新しく宣言し直す「シャドーイング（shadowing）」で
    // 上書きすることはできる。
    let mutable = true;
}
```

## ポイント整理

- スカラ型：整数（`i*` / `u*`）、浮動小数点（`f32` / `f64`）、`char`、`bool`、ユニット `()`。
- 複合型：配列 `[]`、タプル `()`。
- デフォルトの整数型は `i32`、浮動小数点型は `f64`。
- `mut` を付けると値を変更できる（型は変えられない）。
- 同じ名前で再宣言する「シャドーイング」で型ごと上書きできる。
