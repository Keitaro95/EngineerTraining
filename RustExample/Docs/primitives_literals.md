# Literals and operators（リテラルと演算子）

整数 `1`、浮動小数点数 `1.2`、文字 `'a'`、文字列 `"abc"`、真偽値 `true`、そしてユニット型 `()` は、リテラル（literal）として直接書くことができます。

## 数値リテラルの基数（進数）

整数は、接頭辞（プレフィックス）を付けることで、10進数以外でも書けます。

- 16進数 … `0x` を付ける（例：`0xff`）
- 8進数 … `0o` を付ける（例：`0o77`）
- 2進数 … `0b` を付ける（例：`0b1111`）

## 区切り文字（アンダースコア）

数値リテラルの途中にアンダースコア `_` を入れて、桁を読みやすくできます。`_` は値には一切影響しません。

```rust
// 例：1_000 は 1000 と同じ。0.000_001 は 0.000001 と同じ。
let million = 1_000_000;
```

## サンプルプログラム

```rust
fn main() {
    // 整数の足し算
    println!("1 + 2 = {}", 1u32 + 2);

    // 整数の引き算
    println!("1 - 2 = {}", 1i32 - 2);
    // 試してみよう：上の `1i32` を `1u32` に変えると、
    // 型が符号なしのためオーバーフローして、コンパイルエラーになる。

    // 科学的記数法（指数表記）
    println!("1e4 is {}, -2.5e-3 is {}", 1e4, -2.5e-3);

    // 真偽値の論理演算
    println!("true AND false is {}", true && false);
    println!("true OR false is {}", true || false);
    println!("NOT true is {}", !true);

    // ビット演算
    println!("0011 AND 0101 is {:04b}", 0b0011u32 & 0b0101);
    println!("0011 OR 0101 is {:04b}", 0b0011u32 | 0b0101);
    println!("0011 XOR 0101 is {:04b}", 0b0011u32 ^ 0b0101);
    println!("1 << 5 is {}", 1u32 << 5);
    println!("0x80 >> 2 is 0x{:x}", 0x80u32 >> 2);

    // アンダースコアで桁を見やすくする。
    // 可読性が上がる！
    println!("One million is written as {}", 1_000_000u32);
}
```

## 主な演算子

### 算術演算子

`+`（加算）、`-`（減算）、`*`（乗算）、`/`（除算）、`%`（剰余）

### 論理演算子（真偽値）

`&&`（AND）、`||`（OR）、`!`（NOT）

### ビット演算子（整数）

- `&` … ビットAND
- `|` … ビットOR
- `^` … ビットXOR（排他的論理和）
- `<<` … 左シフト
- `>>` … 右シフト

## ポイント整理

- 進数の接頭辞：`0x`（16進）、`0o`（8進）、`0b`（2進）。
- `_` は桁の区切りに使え、値には影響しない（例：`1_000_000`）。
- リテラルにサフィックス（`1u32`, `1i32`, `2.5e-3` など）を付けて型を指定できる。
- フォーマット `{:04b}` は「4桁・ゼロ埋め・2進数」で表示する。
